# Nila-Varnam

## Specification set (documentation phase)

Start at [docs/PROJECT_BLUEPRINT.md](docs/PROJECT_BLUEPRINT.md). The website itself has not been built yet; the build prompt is [docs/prompts/MASTER_PROMPT.md](docs/prompts/MASTER_PROMPT.md).

## Running the site

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # preflight + build + post-build check
```

Temporary placeholder artwork is used until real images are approved. See [docs/ARTWORK_GUIDE.md](docs/ARTWORK_GUIDE.md) and [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).
